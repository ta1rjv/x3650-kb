# x3650-kb - IBM System x3650 M3 reference library

Read it at **https://ta1rjv.github.io/x3650-kb/library/**

A detailed, cross-linked reference library for the IBM System x3650 M3 (machine types 7945, 4255, 7376):
system architecture, hardware components, memory, storage and RAID, error codes, the Integrated Management
Module (IMM v1) and its interfaces, UEFI setup and ASU settings, firmware history and package formats,
sensors, power and thermal behaviour, and the management tool stack. Every fact carries a source and a truth
level (MEASURED, DOCUMENTED, EXTRACTED, CANDIDATE, UNKNOWN, ...).

This repository only hosts the generated static site. It is built automatically from a private engineering
repository; lab-specific identifiers and security findings of the reference unit are removed before
publication. No vendor firmware binaries or documents are published here, only analysis and metadata.
