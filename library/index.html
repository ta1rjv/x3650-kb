About this library #

This library collects what is known about the IBM System x3650 M3, a two-socket 2U rack server of the Westmere-EP generation, sold as machine types 7945, 4255 and 7376 (the same Installation and User's Guide and Problem Determination and Service Guide also cover the IBM Smart Analytics System 5600, type 7949; the "x3650 M3 HF" type 5454 and the x3550 M3 type 7944 are different machines, see sources/SOURCES.md, "Machine types"). It is built from a private engineering knowledge base that combines three kinds of evidence:

  • vendor documents (IBM and Lenovo guides, product guides, white papers, firmware readmes and changelogs),
  • offline analysis of the vendor firmware packages themselves (nothing from a package was ever executed),
  • read-only measurements taken on one reference unit (a machine type 7945 server).

The goal is practical: to understand the management stack (Integrated Management Module, UEFI, IPMI, the firmware update path) well enough to maintain and optimize a machine that IBM and Lenovo no longer document actively. The x3650 M3 is a withdrawn product; much of its documentation now survives only in archived PDFs and in the retired infocenter, which this project mirrored.

Reading truth levels in one minute #

Every fact in the library carries one of these labels (defined in docs/AGENT.md; explained with examples in the reading guide):

Level Meaning
DOCUMENTED Stated in a vendor document; the source id (S-xxx) and page or section is given.
EXTRACTED Read out of a vendor firmware binary or package by offline analysis.
MEASURED Captured read-only from the reference unit (command output kept in the repository).
CANDIDATE An inference; the reason is always stated. Treat as a hypothesis.
UNKNOWN Not established by any source in the repository.

When two sources disagree, both values are recorded and the conflict is listed instead of silently picking one (Knowledge base index, section 4 consolidates 92 conflict topics).

The reference unit #

Measurements in the library come from one machine type 7945 server. Its configuration is described only generically: one Xeon E5606 (4 cores, 2.13 GHz, socket 2 empty), one 8 GB dual-rank RDIMM, a ServeRAID M1015 in the dedicated RAID slot, an IBM 6Gb SAS HBA in a riser slot, one drive backplane, one power supply, factory-level 2011 firmware (IMM 1.30, UEFI 1.13, DSA Preboot 3.48). Everything measured on it was read-only; see the reading guide. Measured values describe that unit, not every x3650 M3.
