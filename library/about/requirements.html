ID Requirement State
REQ-001 Build a knowledge base for the IBM System x3650 M3 in the style of pluto-kb (topic documents, firmware artifacts and baselines, tools, tests, CI). PLANNED
REQ-002 Cover every hardware detail: system board, CPUs/chipset, memory population rules, storage backplanes and RAID controllers, PCIe risers/slots, network, power supplies, fans/thermal, sensors, front panel/light path, part numbers (FRU/option), model 7945KEG specifics. PLANNED
REQ-003 Cover every software/firmware detail: IMM (architecture, SoC, web UI, IPMI, SOL, remote presence, CLI/SSH, SNMP, CIM/WS-Man, user/security model, update mechanism), UEFI, FPDS/DSA diagnostics, firmware package formats, firmware release history, OS/driver support, management tools (ASU, UpdateXpress, ToolsCenter). PLANNED
REQ-004 Use many sources, starting with Lenovo Press TIPS0805 (https://lenovopress.lenovo.com/tips0805-system-x3650-m3), and record a traceable source for every fact. PLANNED
REQ-005 Provide the depth needed for reverse engineering of the IMM and other management interfaces of the owner's own server. PLANNED
REQ-006 Support optimization of the owner's own server (performance, power, thermal and management settings) based on the knowledge base. PLANNED
REQ-007 Keep the repository private on GitHub (ta1rjv/x3650m3-kb). PLANNED
