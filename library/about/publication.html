How this library is published

How the public library is generated from the private repository and what the publication filter removes.

source: site/publish.json, scripts/build_library.py 4 sections

This library is generated by scripts/build_library.py from the private x3650m3-kb repository and rebuilt on every change. The repository holds the full engineering record; this public edition is filtered by scripts/library_sanitize.py with the rules in site/publish.json.

What is redacted #

Identifiers of the owner's unit and lab are replaced by placeholders such as [lab-ip], [mac] or [redacted-id]. Redacted classes: host path, credential file, lab domain, lab ip ten, lab ip guest, mac address, mac ibm compact, proxmox guest, remote access service, lab hostname, and 15 unit identifiers (serial numbers, UUIDs, WWNs and similar). Vendor-documented default addresses and firmware version strings are kept.

What is left out #

Paragraphs, list items and table rows about credentials and key material embedded in vendor firmware images, and about the security posture of the owner's server, are removed completely (10 removal rules). References to security review findings read (security finding, not published). The project state, access map, agent rules and the security review are not published. Firmware binaries and captured server output are listed by name only.

Leak gate #

After every build each output file is scanned for every redaction and removal pattern plus an explicit forbidden list; a single finding fails the build and nothing is published.

Truth levels #

Facts in the volumes carry a truth level, shown as a coloured badge:

MEASURED
Captured from the owner's own server (command output under captures/).
DOCUMENTED
Stated in a vendor document (IBM / Lenovo guide, README, changelog).
EXTRACTED
Read out of a vendor firmware binary or package.
VALIDATED
Checked against a second source or by a test.
CANDIDATE
Inference with a stated reason; not confirmed.
INFERRED
Derived from other facts; not confirmed.
UNKNOWN
Not known; no source found yet.
NOT VERIFIED
Claimed but not verified.
PLANNED
Planned, not done.
