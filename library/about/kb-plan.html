Target: the deepest practical engineering model of the IBM System x3650 M3 (7945KEG) - hardware, IMM, UEFI, firmware formats, management interfaces, error codes, security and optimization - every fact with source and truth level (docs/AGENT.md).

Common inputs #

  • Vendor documents: sources/SOURCES.md, PDFs in sources/pdf/, text in sources/text/ (pdftotext -layout)
  • Archived infocenter: sources/infocenter/7945/ (Wayback mirror)
  • Live captures: captures/ (read-only)
  • Firmware: firmware/ibm/, firmware/lenovo/ (catalog sources/lenovo/CATALOG.md)

Wave Document Scope
1 X3650M3_SYSTEM_ARCHITECTURE.md Block diagram: CPUs, QPI, 5520 IOH, ICH10, DMI, PCIe topology (measured lspci), IMM attachment, video, USB, clocks

1 X3650M3_STORAGE_RAID.md M1015/SAS2008, second HBA, backplanes, drive bays, firmware levels, configuration utilities
1 X3650M3_ERROR_CODES.md POST/UEFI event codes, IMM event log messages, light path, DSA test codes, checkpoint codes, beep codes, symptom tables with actions
1 X3650M3_IMM_ARCHITECTURE.md IMM v1 internals, services, ports, users/auth, LAN-over-USB, banks, update flow, Standard vs Premium, measured config
1 X3650M3_FIRMWARE_FORMATS.md IBM .bin/.exe/.xml/.chg packages, .upd and UEFI image structure, iflash, unpack tooling
1 X3650M3_UEFI.md UEFI architecture, POST flow, setup menus and options, ASU setting names/values, operating modes, image analysis of 1.22 vs 1.14
2 X3650M3_IMM_INTERFACES.md Web UI map, CLI reference, IPMI (standard + IBM OEM), SOL, SNMP MIB, CIM/WS-Man, SLP - from docs plus live read-only probing
2 X3650M3_SENSORS_SDR.md Full SDR decode: sensors, numbers, thresholds, entity IDs, fan zones, measured values
2 X3650M3_POWER_THERMAL.md PSUs, power capping/metering, fan control, thermal thresholds, acoustics
2 X3650M3_TOOLS.md ASU, DSA, UXSPI, BoMC, OneCLI, iflash, ipmitool usage from the Proxmox host
2 X3650M3_SECURITY_REVIEW.md IMM/IPMI/TLS/SNMP posture, CVEs per firmware level, hardening checklist
2 X3650M3_OPTIMIZATION.md Proxmox host tuning: operating mode, C-states, turbo, memory, fans, power, firmware upgrade path
3 X3650M3_KNOWLEDGE_BASE.md Master index and cross-reference
