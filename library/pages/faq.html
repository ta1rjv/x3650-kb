Frequently asked questions #

Short answers with the truth level of the underlying fact. Follow the links for sources; when an answer says UNKNOWN, the library has no source for it.

Identity and hardware #

Which machine types are covered? #

The IBM System x3650 M3, machine types 7945, 4255 and 7376 (DOCUMENTED). Most analysis was done on one reference unit of type 7945. See System at a glance and Hardware 3.1.

Which processors does it take? #

Intel Xeon 5500 (Nehalem-EP) and Xeon 5600 (Westmere-EP), one or two sockets, linked by QPI to an Intel 5520 IOH (DOCUMENTED). Xeon 5600 support arrived with UEFI 1.06 (D6E145C). See System architecture 3 and Firmware history.

How much memory can it hold, and how fast does it run? #

Eighteen DDR3 DIMM slots, nine per processor; speed falls with DIMMs per channel (1 DPC up to 1333 MHz, 3 DPC 800 MHz), and the processor's own memory limit also applies (DOCUMENTED). Only the slots of an installed CPU can be used. See Memory 4.2 and Memory 5.1.

Can I mix RDIMMs and UDIMMs? #

No; the rules forbid mixing registered and unbuffered DIMMs (DOCUMENTED). See Memory 4.1.

Why does the server not beep? #

The vendor states that the server does not use beep codes; it reports through light path LEDs, the checkpoint display, POST error codes and the IMM event log (DOCUMENTED). See Error codes 8 and the Troubleshooting guide.

What are the J29 and J147 jumpers for? #

J29 forces the backup UEFI bank and J147 the backup IMM bank (pins 2-3) for recovery after a failed flash (DOCUMENTED). See Hardware 4.1 and the UEFI guide.

IMM (management controller) #

What is the default IMM login and address? #

Per IBM documentation: user USERID, password PASSW0RD (with a zero), and a static fallback address 192.168.70.125 when DHCP fails (DOCUMENTED). Change the password on first use. See the IMM guide and IMM architecture 6.

Is the IMM the same as IMM2 or XClarity Controller? #

No. The x3650 M3 has the first-generation IMM (IMM v1, builds YUOOxxx); IMM2 and XCC belong to later servers and their manuals do not apply directly (DOCUMENTED). See Firmware history, naming.

Which interfaces does the IMM offer? #

Web (HTTP/HTTPS), legacy CLI over SSH and Telnet, IPMI over LAN (RMCP/RMCP+) and in-band KCS, SOL, SNMP, CIM, WS-Man, SLP and LAN over USB (DOCUMENTED and MEASURED). See IMM interfaces 2 and the IMM guide.

How do I get a remote graphical console? #

Remote presence (KVM and virtual media) needs IMM Premium, enabled by the Virtual Media Key option (DOCUMENTED). Without it, use the serial paths (SOL or CLI serial redirection). See IMM architecture 7 and IMM interfaces 6.

How do I read the IMM event log from the command line? #

Use the CLI command readlog over SSH (five entries per call), or ipmitool sel list for the IPMI SEL (DOCUMENTED, MEASURED). See IMM architecture 10.

What does an IMM event id such as 80010202-2801xxxx mean? #

The first part identifies the event class and sensor type, the second the entity and instance; the decoding is inferred from IPMI sensor events (CANDIDATE) and each id is listed with its vendor text. See Error codes 3 and the Troubleshooting guide.

Why does the IMM web interface feel slow or need old Java/ActiveX? #

The IMM v1 web UI is a frame-based JavaScript application that calls WS-Man for nearly every page; remote control used Java or ActiveX clients (EXTRACTED, DOCUMENTED). See IMM web API 3 and Firmware history.

Firmware #

What is the latest firmware? #

IMM 1.55 (YUOOH5A), UEFI 1.22 (D6E164A) and Preboot DSA 9.53 (DSYTC5F) are the newest levels found (DOCUMENTED); see Firmware history, latest available and the Firmware guide.

In what order should firmware be updated? #

The IMM 1.55 readme recommends IMM first, then UEFI, then Preboot DSA, and some UEFI levels require a minimum IMM level (for example UEFI 1.08 needs IMM YUOO73M) (DOCUMENTED). The IMM can take up to 17 minutes to be ready after an update. See Firmware history, update order and IMM architecture 9.1.

Can I downgrade the IMM? #

With care: going below IMM 1.22 (YUOO84C) requires a factory reset of the IMM configuration (DOCUMENTED). See Firmware history.

Why does a UEFI update need a second reboot? #

The CRTM (boot block) cannot be written while in use; it is staged and applied at the next start (DOCUMENTED). See UEFI 3 and the Firmware guide.

Are IMM firmware images signed? #

The analysed IMM v1 .upd images (1.10 and 1.55) carry MD5/CRC checks, not a cryptographic signature; the UEFI image has an RSA2048-SHA256 trailer on its early boot code (EXTRACTED). See Firmware formats 7.4 and Firmware formats 6.

Where can I still download the packages? #

The IBM delivery servers and the Lenovo support catalog (Data Center Support, "DS" document ids) still served the packages in 2026-10; some need an IBM ID at Fix Central (MEASURED at download time). See Firmware history, open items and About.

Which CPU security fixes need a UEFI update? #

UEFI 1.21 carries Spectre v2 microcode and 1.22 the Speculative Store Bypass microcode (DOCUMENTED). See UEFI 9.

Can I use OneCLI instead of ASU, DSA and UXSPI? #

Whether OneCLI supports this machine type is UNKNOWN in the library; ASU, DSA, UXSPI and BoMC are the documented tools. See Tools 8.

Configuration and tools #

How do I change UEFI settings without a monitor? #

With ASU (asu show, asu set uEFI.<name> <value>) in-band over LAN over USB, or remotely against the IMM address; changes take effect at the next boot (DOCUMENTED). See Tools 4 and UEFI 7.

How do I get a text console on the host serial port? #

Enable console redirection in UEFI and attach through IPMI SOL (COM1) or the IMM CLI console 1 command (COM2) (DOCUMENTED). See the UEFI guide and IMM interfaces 6.

Which operating mode should I pick? #

Acoustic, Efficiency, Performance and Custom presets change speed, C-state and turbo settings; their exact effect on power is CANDIDATE on this platform. See UEFI 6 and Power and thermal 9.

What does LAN over USB do and why is it there? #

It is a USB network link between host and IMM (IMM side 169.254.95.118) used by ASU, DSA and firmware updates (DOCUMENTED). See IMM interfaces 10.

How do I run diagnostics? #

Press F2 at POST to start Preboot DSA from IMM flash, or run DSA Portable from the OS (DOCUMENTED). See Tools 5 and the Troubleshooting guide.

Storage #

Which RAID controller is typical and what can it do? #

The ServeRAID M1015 (LSI SAS2008): RAID 0, 1 and 10, RAID 5/50 with an upgrade key, no cache and no battery (DOCUMENTED). See Storage 4.1 and Storage 9.

Which tool manages the M1015 from Linux? #

StorCLI (the newest Linux build found is 1.16.14); the IBM 6Gb SAS HBA uses SAS2IRCU and SAS2FLASH instead (DOCUMENTED). See Tools 10 and Tools 11.

Can I flash IT firmware over IR on the SAS HBA? #

The bundled SAS2FLASH refuses to cross the IT/IR personality and refuses NVDATA downgrades (EXTRACTED). See Storage 7.1.

About this library #

Can I trust every statement here? #

Each statement carries a truth level: DOCUMENTED and MEASURED facts are strongest, CANDIDATE is reasoning that still needs proof, UNKNOWN means no source. See the Reading guide.

Does the library contain firmware binaries? #

No. It publishes analysis, metadata and checksums only; vendor documents and firmware remain the property of IBM and Lenovo. See About.
