The project #

x3650m3-kb is an engineering knowledge base for the IBM System x3650 M3 server (machine types 7945, 4255 and 7376). It collects every hardware and software detail that public vendor documents, firmware packages and read-only measurements of one reference unit can support. The aim is to understand the management side of the platform (IMM, UEFI, IPMI and the firmware update path) well enough to operate and optimise an owned server safely. Experiments and live tests are limited to the owner's own machine.

The project started on 2026-10-19. The knowledge lives in a private Git repository; this site is a sanitized, read-only rendering of it (decision D-007, 2026-10-21).

Method #

  • Vendor documents first. IBM and Lenovo manuals, product guides, readmes and changelogs were collected and given source ids (S-001 to S-038). Every fact names its source and page. See the Reading guide.
  • Firmware packages analysed offline. Packages were downloaded with their checksums and unpacked by the project's own Python tools without running any vendor code (EXTRACTED facts). See the Firmware guide and Tools guide.
  • Read-only measurements. Inventory, sensors, logs and settings of the reference unit were captured with commands that do not change state (MEASURED facts). State-changing actions such as firmware updates require the owner's explicit approval and are documented as plans, not results.
  • Truth levels. Every statement is marked DOCUMENTED, EXTRACTED, MEASURED, CANDIDATE or UNKNOWN. Nothing is invented to fill a gap; open questions are listed in each volume.

How the repository is organised #

Path Content
docs/ The knowledge volumes (X3650M3_*.md, published here) and project documents (requirements, architecture, decisions, test plan, changelog)
sources/ Source catalog (S-xxx ids), the Lenovo download catalog, an archived IBM InfoCenter subset for the 7945 and a static copy of the IMM 1.30 web interface
firmware/ IBM and Lenovo firmware packages with source URLs and SHA256 sums (the site shows metadata only)
captures/ Read-only command outputs from the reference unit (not published as files)
scripts/ Python analysis tools: package unpacker, IMM .upd and UEFI volume parsers, read-only CIM and WS-Man inventory clients, download and archive helpers
tests/ unittest suite for the scripts, run in CI on every push
site/ Hand-written pages, the file catalog and the publication rules of this site

The file catalog in the Catalogs section describes every directory and file in more detail.

How this site is built #

The site is generated by scripts/build_library.py from the repository:

python3 -m pip install -r requirements-site.txt
python3 scripts/build_library.py --out _site

Volumes are rendered from docs/X3650M3_*.md, these pages from site/pages/*.md, and the catalogs of firmware, sources, scripts and files from repository metadata. Every string passes through a sanitizer with the rules in site/publish.json, and a leak check scans the output; if it finds anything, the build fails and its output is deleted. Internal documents (operating notes, the owner's security assessment and working logs) are never published.

What is not published #

  • Firmware binaries and vendor document files. Only names, versions, dates, sizes and SHA256 checksums appear.
  • Addresses, host names, network layout, serial numbers, UUIDs and MAC addresses of the owner's equipment.
  • The owner's security assessment and anything that would describe weaknesses of a specific live system. Vendor-published CVE lists per firmware level are public information and remain.
  • Credentials of any kind. The IBM factory defaults quoted in the guides come from IBM's own documentation.

Copyright and license #

IBM and Lenovo documents, firmware and web interface files remain the property of their owners. This site publishes original analysis, short quotations for reference and metadata about vendor files; it does not redistribute vendor binaries. IBM, System x, ServeRAID, Lenovo and XClarity are trademarks of their respective owners. The site is an independent engineering reference and is not affiliated with or endorsed by IBM or Lenovo.

Limitations #

  • One reference unit was measured; other configurations are described from vendor documents only.
  • Vendor documents of this era are partly withdrawn; some were read from archives (see the Reading guide).
  • Firmware updates and other state-changing tests were not performed; their outcome is described as PLANNED or CANDIDATE where it appears at all.
