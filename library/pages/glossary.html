Glossary

More than 100 terms of the x3650 M3 platform, its IMM, UEFI, firmware packaging, storage and tools, each with a one-line definition and a link to the volume section that explains it.

One line per term; follow the link for sources and detail. Terms specific to IBM System x of the IMM v1 era are explained as used on the x3650 M3; IMM2 or XClarity meanings are noted where they differ.

A - C #

Term Definition See
ABR Automatic boot failure recovery: the IMM starts the backup UEFI bank when the primary fails during start (POST 3048006). Error codes 13
ACPI Firmware tables (DSDT, SSDT, MADT, DMAR, MCFG, HPET, FACP) that describe the platform to the OS. System architecture 12
Action catalog (A01-A64, D01-D28) Condensed vendor "user response" texts shared by many IMM events (A) and DSA messages (D). Error codes 5, 11
AEM Active Energy Manager: IBM Systems Director extension for power metering and capping through the IMM; UEFI "Capping Enabled" by default. Power and thermal 5.1
Altimeter Pressure sensor that works with the IMM to govern fan speed. Hardware 11.1
ASU Advanced Settings Utility: reads and writes UEFI, IMM and iSCSI settings by name, in-band or out-of-band. Tools 4
Authority level IMM v1 user rights: Supervisor, Read Only or Custom (individual rights); mapped to IPMI privileges. IMM architecture 6
Backup bank Second firmware copy of the IMM or UEFI used for recovery; selected by J147 / J29 or automatically. IMM architecture 3.2
BBU Battery backup unit for RAID cache; not used by the cacheless M1015, optional on M5014/M5015. Storage 9
BCM5709 Broadcom NetXtreme II dual-port Gigabit Ethernet controller on the system board (TOE, WoL, VLAN). System architecture 10
BDS Boot Device Selection, the last UEFI phase, which runs the boot manager. UEFI 2
Beep codes Not used: "This server does not use beep codes for server status". Error codes 8
BMC Baseboard management controller; on this server the BMC function is part of the IMM. IMM architecture 3.1
BoMC Bootable Media Creator: builds bootable media with Preboot DSA, UXSPI and update packages. Tools 7
Bootcode Boot firmware component of the BCM5709 NVRAM (bc), one of several images in the NIC package. Firmware formats 12
BRD LED Light path LED for a system-board problem: battery, missing riser, or failed voltage regulator. Hardware 6.3
Build ID Firmware build name such as YUOOC7E (IMM), D6E164A (UEFI), DSYTC5F (DSA); maps to a version number. Firmware history, naming
Capsule_P.scap UEFI image holding the early boot code (SEC/PEI) with an RSA2048-SHA256 signature trailer. Firmware formats 6
CDC Ethernet / RNDIS USB network device classes used by the IMM for LAN over USB (USB ID 04b3:4010). IMM architecture 4.2
cdc_interface.sh IBM helper script in tool and firmware packages that configures the host side of LAN over USB. Tools 3
.chg Change-history file published next to each IBM firmware package. Firmware formats 4
Checkpoint code Two-digit progress code shown on the light path panel during boot; a location, not an error code. Error codes 7
Chipkill Memory error correction that tolerates a failed DRAM chip; requires x4-based DIMMs. Memory 7
CIM Common Information Model; the IMM serves CIM-XML over HTTP 5988 / HTTPS 5989 for IBM Systems Director. IMM interfaces 8
CNFG LED Light path LED for a configuration error, lit together with CPU or MEM. Error codes 9.1
COM1 / COM2 Host serial ports; on rack servers COM1 carries IPMI SOL and COM2 serves CLI serial redirection. IMM interfaces 6
Cooling zone Fan-control zone exposed as an IPMI sensor (Cooling Zone 1-3). Sensors and SDR 5
CRTM Core Root of Trust for Measurement: locked boot-block region of UEFI, updated by a staged capsule at the next boot. UEFI 2
CRU / FRU Customer replaceable unit (Tier 1 by the customer, Tier 2 optional) versus field replaceable unit (trained technician). Hardware 13
CSM Compatibility support module: legacy BIOS boot inside UEFI (LegacyBios module). UEFI 2

D - I #

Term Definition See
DASD Direct access storage device: IBM term for disk drives (DASD LED, DASD backplane). Hardware 9
DPC DIMMs per channel; determines the maximum memory speed (1 DPC 1333, 3 DPC 800 MHz). Memory 5.1
DSA Dynamic System Analysis: IBM inventory, log collection and diagnostics tool (Preboot and Portable editions). Tools 5
DSA message (CCC-TTT-xxx) DSA Preboot result id: component, test state (8xx aborted, 9xx failed). Error codes 10
DXE Driver Execution Environment, the UEFI phase that loads drivers and the Setup engine. UEFI 2
ESI Enterprise Southbridge Interface, the DMI-compatible x4 link between the 5520 IOH and ICH10. System architecture 4
Event ID IMM message id AABBCCDD-EEFFxxxx; structure inferred from IPMI sensor events (CANDIDATE). Error codes 3
Fix Central IBM's firmware download portal; some x3650 M3 packages need an IBM ID login there. Firmware history, open items
FoD Features on Demand: license-key mechanism of IMM2-era systems; not an IMM v1 feature, although the 1.55 image carries FoD key-import code. Firmware formats 7.9
FRU (IPMI) IPMI inventory record of a part (board, supply, DIMM, backplane) with part and serial numbers. Hardware 14
FV / FFS UEFI firmware volume and its file system; the x3650 M3 image has five FFS2 volumes and 178 modules. Firmware formats 6
G200eV Matrox video controller integrated in the IMM, 16 MB. System architecture 8
HII Human Interface Infrastructure: UEFI forms and strings from which Setup pages are rendered. UEFI 5
ICH10 Intel I/O controller hub (southbridge): USB, SATA, LPC, SMBus, serial ports. System architecture 6
IFR Internal Forms Representation, the byte code of HII forms (questions, defaults, conditions). UEFI 5
iflash / iflash64 Host-side flash utility inside IBM IMM, UEFI and DSA packages. Firmware formats 8
IMM Integrated Management Module: the service processor (BMC, video, remote presence) of the x3650 M3. IMM architecture 3
IMM event log The IMM's text event log (filtered SEL plus IMM events), read with readlog or the web page. IMM architecture 10
IMM v1 / IMM2 / XCC First IMM generation (x3650 M3, YUOO builds) versus its successors on M4/M5 and later servers; facts are not interchangeable. Firmware history, naming
IOH (5520) Intel 5520 I/O hub: PCIe root ports, QuickData DMA, VT-d; linked to the CPUs by QPI. System architecture 4
IPMI Intelligent Platform Management Interface 2.0, implemented by the IMM over KCS and LAN. IMM interfaces 5
IT / IR firmware LSI SAS2 HBA personalities: IT = initiator-target (plain HBA), IR = integrated RAID; flashers refuse to cross them. Storage 4.2

J - P #

Term Definition See
J29 UEFI boot recovery jumper; pins 2-3 load the backup UEFI page. Hardware 4.1
J147 IMM recovery jumper; pins 2-3 load the backup IMM page. Hardware 4.1
JFFS2 Flash file system used for the IMM root and boot file systems (big-endian). Firmware formats 7
KCS Keyboard Controller Style: the in-band IPMI system interface (I/O 0xCA2); no authentication from the host. IMM architecture 4.1
LAN over USB Virtual Ethernet link between host OS and IMM (IMM 169.254.95.118) used by ASU and firmware updates. IMM interfaces 10
LDAP Directory authentication for IMM web and CLI logins; IPMI always uses local accounts. IMM architecture 6
Legacy CLI IMM v1 command line over SSH or Telnet (system> prompt). IMM interfaces 4
Light path diagnostics Front pull-out LED panel plus board LEDs that point to the failing component. Hardware 6
linwrap / wrapcfg Linux wrapper and its configuration inside IBM packages that start the flash tool. Firmware formats 3
Locator LED Blue LED to identify the server in a rack; also controlled by CLI identify. Hardware 6.1
M1015 IBM ServeRAID M1015: LSI SAS2008 MegaRAID adapter, RAID 0/1/10 (5/50 with key), no cache. Storage 4.1
MegaRAID LSI RAID firmware family used by ServeRAID M-series adapters; managed with StorCLI, WebBIOS, MSM. Storage 8
Memory mirroring Mode that duplicates memory across channel pairs (3+6, 2+5, 1+4); half the capacity usable. Memory 6.2
Microcode CPU patch shipped in the UEFI FvMicrocode.fv volume (six updates per image). UEFI 9
mriName Attribute in the UEFI setup XML that forms the ASU setting name (uEFI.<mriName>). UEFI 7
NC-SI Network controller sideband interface: lets a BMC share a host NIC port; the BCM5709 runs NC-SI firmware. Firmware formats 12.4
NMI Non-maskable interrupt; NMI LED and recessed NMI button on the light path panel. Hardware 6.3
Nx boot failure After N failed POST attempts (3, 6, 9) the firmware loads defaults and starts Setup. Error codes 13
NVDATA Non-volatile configuration data of an LSI controller, versioned separately from its firmware. Storage 7
NVRAM variables UEFI variables (boot entries, console paths, Setup store) kept in flash. UEFI 12
oem_ibm.xml Descriptor inside a UEFI .upd with firmware type, build, version and release date. Firmware formats 5
Online spare Memory sparing mode: one DIMM per CPU set held in reserve (Xeon 5600 only); 2/3 usable. Memory 6.3
Operating mode UEFI preset (Acoustic, Efficiency, Performance, Custom) for speed, C-state and turbo settings. UEFI 6
OVER SPEC Light path LED: shutdown because a 12 V power channel was overloaded. Error codes 9.4
Patrol Read RAID controller background scan of drives for media errors. Storage 9
Patrol / demand scrub Memory scrubbing settings in UEFI (uEFI.PatrolScrub, uEFI.DemandScrub). Memory 7
PEI / SEC Earliest UEFI phases (security and pre-EFI initialisation: CPU, QPI, memory). UEFI 2
PET Platform Event Trap: IPMI alert sent as an SNMP trap. IMM interfaces 5.6
PFA Predictive Failure Analysis alerts (memory, drives). Memory 7
PKG SDK IBM self-extracting package format: stub + unzip + image.tar + image.zip + imgboot.cfg + 20-byte trailer. Firmware formats 3
POST Power-on self-test; POST error codes are seven hex digits on this server. Error codes 6
POST event log Setup view of the three most recent POST errors. Error codes 2
Power channel One of the 12 V rails A-E and AUX on the system board, each with an error LED. Error codes 9.4
Power restore policy What the server does when AC returns (Restore, Always Off, Always On). UEFI 7
Preboot DSA DSA stored in IMM flash and started with F2 at POST. Tools 5.7
Premium (IMM) IMM feature level enabled by the Virtual Media Key: remote presence, virtual media, failure screen capture. IMM architecture 7

Q - Z #

Term Definition See
QPI QuickPath Interconnect, the CPU-to-CPU and CPU-to-IOH link (up to 6.4 GT/s). System architecture 3
RDIMM / UDIMM Registered versus unbuffered DDR3 DIMMs; never mixed; different maximum counts. Memory 4.1
readlog IMM CLI command that pages through the IMM event log five entries at a time. IMM architecture 10
Remind button Light path button that puts the system-error LED into a slow-flash remind mode. Hardware 6.2
Remote presence Graphical remote console (KVM) and virtual media on port 3900; Premium feature. IMM architecture 4.3
RETAIN tip IBM service tip (Hxxxxxx) documenting a known problem, for example H206034 (IMM failover defect). IMM architecture 3.2
Riser PCIe riser-card assembly; two on the board (slots 1-2 and 3-4), plus the SAS riser with the RAID slot. Hardware 8
RMCP / RMCP+ IPMI-over-LAN session protocols (IPMI 1.5 / 2.0) on UDP 623. IMM architecture 5.5
SAS2008 LSI 6 Gb/s SAS controller chip used by both the M1015 and the IBM 6Gb SAS HBA. Storage 1
SAS2IRCU / SAS2FLASH LSI command-line tools for SAS2 HBA volumes and firmware flashing. Tools 11
SDR Sensor data repository: IPMI records describing every sensor (type, entity, thresholds, hysteresis). Sensors and SDR 3
SEL System event log (IPMI); fixed size, does not overwrite when full. Error codes 2
Sensor type / entity IPMI codes classifying a sensor (for example 02 voltage) and the part it watches (28 battery). Error codes 3
Serial redirection IMM CLI console 1: host COM2 carried over SSH or Telnet. IMM interfaces 6
ServerProven IBM/Lenovo compatibility list of options per server; the x3650 M3 page is gone. Memory 14
SFCB Small Footprint CIM Broker, the CIM server inside the IMM (sfcHttpd). IMM interfaces 8
SLP Service Location Protocol (427): the IMM advertises its management services for discovery. IMM interfaces 9
SMBIOS OEM strings Type 11 strings where IBM records firmware builds and banks (for example "$CF Current UEFI Flash Bank"). IMM architecture 2
SNMP IMM agent (v1 and v3) on 161/udp and traps on 162/udp. IMM interfaces 7
SOL Serial over LAN: IPMI payload carrying the host COM1 console over UDP 623. IMM interfaces 6
SPD Serial presence detect: DIMM EEPROM with size, ranks, device width and timing. Memory 7
StorCLI Command-line utility for MegaRAID controllers such as the M1015. Tools 10
SW3 / SW4 System-board switch blocks: clear CMOS, TPM physical presence, password and power overrides. Hardware 4
Tier 1 / Tier 2 CRU Tier 1 parts are replaced by the customer; Tier 2 by the customer or, on request, by IBM service. Hardware 13
TOE TCP offload engine feature of the BCM5709. System architecture 10
TPM Trusted Platform Module 1.2 on the LPC bus; disabled by default in UEFI. UEFI 7
U-Boot Boot loader of the IMM SoC; selects the active firmware side. IMM architecture 3.2
UBI Linux volume layer on the IMM NAND with two copies (sides) of kernel and file systems. IMM architecture 3.2
UEFI Unified Extensible Firmware Interface: the x3650 M3 system firmware (UEFI 2.1, IBM builds D6Exxx). UEFI 1
uImage U-Boot kernel image; in IMM packages a big-endian MIPS Linux 2.6.16.46 kernel. Firmware formats 7
.upd Flash payload inside IBM packages: a tar of a descriptor and the images. Firmware formats 5
UXSP / UXSPI UpdateXpress System Pack (tested bundle of updates) and its installer. Tools 6
VBAT Planar VBAT sensor: CMOS battery voltage (lower critical 2.095 V on the reference unit). Hardware 12
Virtual Light Path IMM web page showing the state of every light path LED remotely. IMM interfaces 3.2
Virtual Media Key Option 46C7526 that upgrades the IMM to Premium. IMM architecture 7
VPD Vital product data: machine type, serial and firmware levels reported by the IMM (vpd command). IMM interfaces 3.2
VSC452 Vitesse "SuperBMC" PCI identity of the IMM; CANDIDATE as the IMM SoC. IMM architecture 3.1
VT-d / DMAR Intel I/O virtualisation (IOMMU) in the 5520 IOH, described by the ACPI DMAR table; off by default in UEFI 1.22. System architecture 4
Watchdog POST watchdog (UEFI) and OS / loader watchdogs (IMM) that restart a hung server. IMM architecture 4.5
WebBIOS Pre-boot configuration utility of MegaRAID adapters (Ctrl+H; HII browser under UEFI). Storage 8
Westmere-EP Intel Xeon 5600 generation (CPUID 0x206Cx); the Xeon 5500 predecessor is Nehalem-EP. UEFI 9
WS-Man WS-Management SOAP interface on /wsman; the IMM web UI uses it for almost every page (133 operations). IMM web API 5
YUOO Prefix of IMM v1 build ids (letter O twice, not zeros). Firmware history, naming
