DSA Preboot DSYTxxx ibm_fw_dsa_dsytXXX-<ver>_<os>_<arch>
IMM2 (M4/M5 - other generation) 1AOO, TCOO ibm_fw_imm2_..., .uxz - do not mix with IMM v1

Linux .bin packages are self-extracting; -x <path> extracts without flashing, -s/-u silent (IMM 1.55 README, firmware/ibm/imm/1.55-yuooh5a/). iflash options: --package --user --password --unattended --force --backup --no-reboot; --backup writes the secondary (backup) bank.

Update order and safety (DOCUMENTED) #

  • Recommended order: IMM, then UEFI, then DSA Preboot (IMM 1.55 README). Full plan for this server (PLANNED, nothing executed): docs/X3650M3_FIRMWARE_UPDATE_PLAN.md.
  • The IMM runs "a full operating system" and can take up to 17 minutes to be ready after an update (Firmware update best practices for IMMv1 systems, p.7, sources/pdf/S-022_*).
  • IMM has primary and backup banks. A "firmware architecture change from Q3 2011" makes mixed-bank images unpredictable (https://www.ibm.com/support/pages/node/860842).
  • Physical IMM recovery jumper: J147 (pins 1-2 primary IMM image, 2-3 secondary) and UEFI boot backup jumper J29 (S-004 Table 4, printed p.18-20; S-002 printed p.29-31; details in docs/X3650M3_IMM_ARCHITECTURE.md).
  • This server hosts the lab (docs/AGENT.md): any update needs explicit owner approval and a rollback plan.

Conflicts #

  • Installed UEFI build D6E154A is not in the 1.22 .chg (which lists 1.13 = D6E154B); UXSP 5.00 lists d6e154a. SMBIOS reports D6E154A as version 1.13 (MEASURED), so it is a 1.13 build; why the .chg names D6E154B is UNKNOWN.
  • UEFI 1.11: D6E150C (IBM tip snippet) vs D6E150D (.chg).
  • IMM build strings appear as "YU00..." (digit zero) in some field reports; the measured VPD reads YUOOC7E.

Open items #

  • IMM 1.55 binary: IBM Fix Central needs an IBM ID login. The same IMM package is listed for QRadar M3 appliances (https://www.ibm.com/support/pages/qradar-m3-firmware-v22-xseries-2u-xx05-and-xx24-appliances-premusb).
  • IMM SoC, kernel, flash layout: EXTRACTED for 1.10 (MIPS32, vsc452 drivers, Linux 2.6.16.46, NAND/UBI two-side layout; docs/X3650M3_FIRMWARE_FORMATS.md 7, docs/X3650M3_IMM_ARCHITECTURE.md 3.1-3.2); UNKNOWN for the installed 1.30 (no 1.30 imm_*.upd locally).
  • RE lead https://github.com/smx-smx/tools (ibmextract): inspected 2026-10-21, POWER .pak only, not applicable (docs/X3650M3_FIRMWARE_FORMATS.md 7).
