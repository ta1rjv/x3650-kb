Conventions:

  • Page numbers "p.N" are the printed page numbers of S-004. PDF page index = printed page + 18 for the body of 00kc219.pdf (verified: printed 52 = PDF 70, 274 = 292, 289 = 307, 363 = 381).
  • Truth levels: DOCUMENTED (vendor document), EXTRACTED (firmware binary), MEASURED (owner's server), CANDIDATE (inference, reason given), UNKNOWN. Every table below states its level; a row inherits the table level.
  • Tables in sections 4, 6, 10 and 12 were extracted with scripts from the S-004 text layer (pdftotext) and cross-checked against the infocenter pages (same 655 IMM IDs, same 45 POST codes, same 63 DSA IDs).
  • Action text is condensed. Abbreviations: [TT] = "(Trained service technician only)"; [DIMM note] = "Each time you install or remove a DIMM, disconnect the server from power and wait 10 seconds before restarting"; [cluster note] = "some cluster solutions need specific/coordinated code levels; verify before updating"; cross-references such as "(see ... on page N)" and URLs were removed. SERV-CALL = IBM "Before you call" page. Where text was truncated the row says "full text: S-004 p.N".
  • IMM message placeholders are shortened: [NumSensor]/[Sensor] = [NumericSensorElementName]/[SensorElementName], [System] = [ComputerSystemElementName], [DIMM] = [PhysicalMemoryElementName], [MemSubsys] = [MemoryElementName], [CPU] = [ProcessorElementName], [Drive] = [StorageVolumeElementName], [PowerSupply], [Package], [Connector] analogous; [argN] are message arguments.

Message severities in the system event messages log (S-004 p.31): Information (no action), Warning (no immediate action, possible problem), Error (may require action). IMM web log marks Warning "W" (yellow) and Error "E" (red) (S-020 p.99). IMM remote alert classes: Critical, Warning, System (S-020 p.31-32).

3. IMM event ID structure #

Truth level: CANDIDATE. S-004 lists IDs but does not define their structure. The decode below is inferred from the 655 documented IDs and their sensor names. The DD values agree with the IPMI sensor-type numbers printed by ipmitool on this server (captures/2026-10-19_ipmi_inband.txt sdr type list); the BB (event/reading type) and EE (entity ID) readings follow the IPMI 2.0 numbering from memory of the specification, which is not in sources/ (open question Q-03).

Format AABBCCDD-EEFFxxxx (also shown as AABBCCDDEEFFxxxx or 0xAABBCCDDEEFFxxxx, S-004 per message):

Field Meaning (CANDIDATE) Values in the catalog
AA 80 = assertion, 81 = deassertion of an IPMI sensor event; 40 = IMM-internal event (no sensor; then BBCCDD is a message number and the second half is 00000000) 80, 81, 40
BB IPMI event/reading type: 01 threshold, 03 discrete state, 07 generic severity, 0b redundancy, 6f sensor-specific see counts below
CC Event offset within the reading type (e.g. threshold 02 = lower critical going low, 09 = upper critical going high; sensor-specific offset) 00-0b
DD IPMI sensor type (01 temperature, 02 voltage, 04 fan, 07 processor, 08 power supply, 09 power unit, 0c memory, 0d drive slot, 0f system firmware progress/error, 10 event logging disabled, 12 system event, 13 critical interrupt, 21 slot/connector, 23 watchdog 2, 25 entity presence) see counts below
EE IPMI entity ID of the sensor (e.g. 03 processor, 04 disk/disk bay, 07 system board, 0a power supply, 13 power unit, 1d fan, 20 memory device, 22 system firmware, 28 battery) see counts below
FF Entity instance (DIMM n = 20nn hex, Drive n = 04nn, fan n = 1dnn, CPU n = 03nn) -
xxxx Not used for lookup (event-specific data) -

4. IMM event-log messages (655 event IDs) #

Truth level: DOCUMENTED (S-004 "Integrated management module error messages", p.31-274; identical ID set in S-005 15th edition and in IC r_imm_messages.html). Columns: Sev = severity (Info/Warning/Error); Svc = serviceable; CH = "Automatically notify Support" (call home; Yes for 101 IDs, S-004 Table 9 p.31ff); Category = alert category; CIM = CIM prefix:ID; Trap = SNMP trap ID; Action = key into section 5 ("info" = no action, information only); "also" = other sensor names that S-004 lists for the same event ID.
