1. Machine overview (as measured) #

The owner's server is an IBM System x3650 M3, type-model 7945KEG, serial [redacted-id] (HW 2), and it is also the Proxmox VE 8.4.0 host [lab-ip] (hostname [lab-host], pve-manager 8.4.21, kernel 6.8.12-43-pve) that runs the agent container (TOOLS 2; ASSUMPTIONS A-007). It has one Intel Xeon E5606 2.13 GHz (4 cores, Westmere-EP, model 44 stepping 2) in socket 1 with socket 2 unpopulated (HW 2, SYSARCH 3), running microcode 0x14 (OPT 1). Memory is one 8 GB RDIMM in slot DIMM03 (SK Hynix HMT31GR7BFR4A-H9, 2 ranks, x4) at 1067 MT/s, 17 of 18 slots empty (MEM 1, MEM 9). Storage is a ServeRAID M1015 (LSI SAS2008, firmware package 20.10.1-0052, no Advanced Feature Key, no BBU) with VD 0 (RAID0, 231.898 GB, Toshiba MK2546GSX at 64:0, Proxmox boot disk /dev/sda) and, since 2026-10-20, VD 1 "hitachi_data" (RAID0, 110.827 GB, Hitachi HTS542512K9SA00 at 64:1, /dev/sdb, ext4, Proxmox storage hitachi-data, target of the weekly vzdump job); neither VD is redundant; a second SAS2008 HBA (IBM 6Gb SAS HBA 9212-4i4e) has no devices attached (STOR 1). SMART on 2026-10-20: Toshiba 14179 power-on hours, no logged error; Hitachi 1311 power-on hours, 0 reallocated/pending, 140 logged ATA UNC read errors at 1189 h; no self-test has ever run on either drive, long self-tests are queued (STOR 6.1). The IMM sees one power supply, named "Power Supply 2" in IPMI FRU/SDR but "Power Supply 1" in its own VPD (FRU 39Y7229, CANDIDATE 460 W AC) (HW 10). Firmware is from 2011: IMM build YUOOC7E version 1.30 (2011-09-30), UEFI build D6E154A reported by SMBIOS as 1.13 (2011-09-23), DSA Preboot DSYT89P (2011-10-28); the latest documented levels are IMM 1.55 YUOOH5A and UEFI 1.22 D6E164A (FWH installed levels, FWH latest, IMMA 2). Measured problems: CMOS battery Planar VBAT below the 2.095 V lower critical threshold (latest reading 1.791 V on 2026-10-20, 1.727 V on 2026-10-19; HW 12, SDR 10, SDR 4.1), SEL full since 2025-05-05 (ASSUMPTIONS A-008), and a boot-drive event: the M1015 failed the Toshiba drive (slot 0) on 2026-10-14 after write timeouts and found it again at the next start, and the IMM logged "Drive 0 disabled due to a detected fault" on 2026-10-17 while the controller now reports the drive Online with zero error counters (STOR 14.4, STOR 12 C-10, open). Project state and known issues: STATUS.md.
