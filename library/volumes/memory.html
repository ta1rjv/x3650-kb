2. Memory subsystem architecture #

  • Each Xeon 5500/5600 CPU has its own integrated memory controller; memory attached to the other CPU is reached over QPI (NUMA). Source: S-001 "Memory options" and the preceding NUMA paragraph (lines about processors accessing the memory of another processor). Level: DOCUMENTED.
  • Three DDR3 channels per CPU, three DIMM connectors per channel. Source: S-001 "Memory options" ("Each processor has three memory channels, and there are three DIMMs per channel"); S-002 Table 11. Level: DOCUMENTED. EDAC reports max_location: channel 2 slot 2 (3 channels x 3 slots) for the single controller. Source: captures/2026-10-19_mem_storage_memory.txt (EDAC section). Level: MEASURED.
  • One CPU socket populated => only DIMM connectors 1-9 are usable. CPU2 connectors 10-18 are associated with socket 2. Source: S-002 Figure 123 text ("DIMM connectors 10-18 ... microprocessor 2 ... 1-9 ... microprocessor 1"); infocenter c_memory_mirroring_option. Level: DOCUMENTED.
  • Chipset on the board: Intel 5520 IOH (TIPS0805) - not in the memory path (the IMC is in the CPU). Open point on the "5600" chipset wording in ZG11-0012 is tracked in sources/SOURCES.md and is out of scope here.
  • Only one MC is detected on the owner's server because socket 2 is empty. Source: EDAC capture ("1 MC detected", Driver loaded, 1 memory controller(s) found). Level: MEASURED.

4. DIMM types, sizes, ranks and limits #

4.1 General rules #

  • Industry-standard DDR3 800/1066/1333 MHz, PC3-10600R class, registered or unbuffered, ECC. Only the types in 4.2/4.3 are supported. Source: S-002 "Installing a memory module". Level: DOCUMENTED.
  • UDIMMs and RDIMMs must not be mixed in one server. Source: S-002 (two bullets); S-001 "Memory options". DOCUMENTED.
  • Maximum DIMM count by type: 18 single/dual-rank RDIMMs; 12 UDIMMs or quad-rank RDIMMs (2 per channel). Source: S-002 Installing a memory module; S-001 "Memory options" ("UDIMMs can only be populated two DIMMs per channel"; quad-rank RDIMM max 12). Level: DOCUMENTED.
  • At least one DIMM per installed CPU; at least three per CPU recommended for performance. Source: S-002. Level: DOCUMENTED.
  • One quad-rank RDIMM in a channel goes into the connector furthest from the CPU; do not combine one quad-rank RDIMM in one channel with three RDIMMs in another. Source: S-002. Level: DOCUMENTED.
  • 32-bit OS: some memory is reserved for system resources. Source: S-002. Level: DOCUMENTED.
  • On label decoding (ggg eRxff-PC3-wwwwwm-aa-bb-cc: capacity, ranks, device width x4/x8/x16, bandwidth, type R/E/U, CAS latency): S-002. Level: DOCUMENTED.

5. Speed and voltage rules #

5.1 Speed vs DIMMs per channel (DPC) #

Config S-002 (IUG) rule S-001 (TIPS0805) rule (Xeon 5600)
1 DPC 1333 MHz 1333 MHz (1 or 2 single/dual-rank RDIMM per channel, or 1 UDIMM per channel)
2 DPC 1066 MHz; up to 1333 MHz with X5600 under two conditions (see 5.2) 1333 MHz (RDIMM single/dual rank); 1066 MHz with 2 UDIMM per channel
3 DPC 800 MHz 800 MHz (3 single/dual-rank RDIMM per channel, or 2 quad-rank RDIMM per channel)
1 quad-rank RDIMM per channel not stated 1066 MHz

Common to both: all channels run at the fastest common frequency (S-002) / at the slowest DIMM (mirroring and sparing text, S-002); maximum speed = min(CPU limit, DIMM speed rating, DPC limit). Level: DOCUMENTED. The two documents differ for 2 DPC: see conflict C-3.

5.2 1333 MHz at 2 DPC (S-002 bullet) #

A server with an Intel Xeon X5600 series CPU runs at up to 1333 MHz with two DIMMs per channel when:

  • two 1.5 V single/dual-rank RDIMMs per channel and Setup "Memory speed" = Max performance, or
  • two 1.35 V single/dual-rank RDIMMs per channel, "Memory speed" = Max performance and "LV-DIMM power" = Enhance performance; the 1.35 V RDIMMs then run at 1.5 V.

Source: S-002 and S-004 ("Installing a memory module"). Level: DOCUMENTED. The text says "X5600 series"; whether the E5606 qualifies is not stated (it is a Xeon 5600 series part but is limited by its own memory-speed rating, see 5.3). The UEFI 1.22 setup XML additionally has uEFI.Plt2DPC1333Capable ("2DPC1333 Capable", default Disable) and uEFI.Enable2DPCOverclock ("2DPC Overclocking", default Disable) (docs/X3650M3_UEFI.md Appendix A, EXTRACTED); their relation to the S-002 conditions is not documented (CANDIDATE: firmware side of the same rule).

5.3 CPU limit #

  • TIPS0805 states "up to 1333 MHz memory speed" for the 5600 family and lists per-model memory speeds: model 7945-22x (1x Xeon E5606 2.13 GHz, 4C, 8 MB) = 1066 MHz; E5645/X5650/L5640 models = 1333 MHz. Source: S-001 Table 1 (standard specifications) and Table 2 (standard models). Level: DOCUMENTED. S-001 "Memory options" also states that the maximum memory speed is limited by the processor's supported speed and by the DIMM count/type, whichever is lower.
  • The owner's CPU is an E5606 (captures/2026-10-19_hw_cpuinfo.txt, model 44, stepping 2). Level: MEASURED. The maximum DDR3 speed of this CPU is therefore 1066 MHz (DOCUMENTED via the 7945-22x row; the DIMM in the machine runs at the same value, MEASURED, section 9).
  • Only the 7945-22x row of S-001 Table 2 names the E5606; the E5606 is not in the S-001 processor option table. Other 4C rows with "1066 MHz" (E5603, E5607, E5620) use other CPUs.
  • Intel specification for the E5606 (intel.com ark, SKU 52583, "Intel Xeon Processor E5606 (8M Cache, 2.13 GHz, 4.80 GT/s Intel QPI)" specifications page, research 2026-10-21): memory types DDR3 800/1066, 3 channels, max 288 GB, max bandwidth 25.6 GB/s, ECC supported, QPI 4.8 GT/s with 2 links, TDP 80 W, no Turbo, no Hyper-Threading. RAS per the Xeon 5600 datasheet vol 2 (Table 3-1, Sec 3.4): x4 SDDC in independent channel mode, x8 SDDC in lockstep (Ch0+Ch1), mirroring Ch0+Ch1 with Ch2 empty, sparing with Ch2 as the spare (5600 only). DOCUMENTED. Supported DIMM voltages for this SKU are not listed on the ark page (UNKNOWN beyond the S-001 family statement).

5.4 Voltage #

  • Server supports 1.5 V and 1.35 V (low-voltage, "PC3L") DDR3 DIMMs. Mixing 1.5 V and 1.35 V DIMMs is supported on Xeon 5600 systems; all DIMMs then run at 1.5 V. Xeon 5500 systems do not support 1.35 V DIMMs. Source: S-001 "Memory options". Level: DOCUMENTED.
  • 1.35 V DIMMs "consume 20 percent less energy". Source: S-001 (features list). Level: DOCUMENTED (vendor claim).
  • Correction 2026-10-21: ipmitool prints 1.5 V Nominal Op: Yes, 1.35 V Nominal Op: No, 1.2X V Nominal Op: Yes (captures/2026-10-19_ipmi_inband.txt, FRU DIMM 3, MEASURED). ipmitool lib/dimm_spd.c prints "No" when the bit is set for all three bits of SPD byte 6 ((spd_data[6]&2) != 0 ? "No":"Yes", https://raw.githubusercontent.com/ipmitool/ipmitool/master/lib/dimm_spd.c), but JEDEC Std 21-C 4.1.2.11 (DDR3 SPD, byte 6 "Module Nominal Voltage, VDD") defines bit 0 = 1 as "NOT 1.5 V operable" and bits 1 / 2 = 1 as "1.35 V operable" / "1.25 V operable". "1.2X V" is the 1.25 V bit. The printed lines therefore mean byte 6 = 0x02: 1.5 V operable, 1.35 V operable, not 1.25 V operable (CANDIDATE, derived from the ipmitool source and JEDEC; the raw byte was not read). The earlier statement "1.5 V only" rested on the inverted ipmitool text and is withdrawn; the module runs at 1.5 V here in any case (single DIMM, LV-DIMM Power "Low Power" acts only with two 1.35 V DIMMs on a channel and a 1333 MHz CPU, UEFI help text, docs/X3650M3_UEFI.md 12.7).
  • UEFI controls: Memory speed, LV-DIMM power (see 8).

6. Population rules and order per mode #

Modes named in the vendor documents: normal (independent channels), memory mirroring, online-spare (sparing). No document in the local source set mentions a "lockstep" mode for this server, and the UEFI 1.22 setup XML offers only Independent (default), Mirroring and Sparing for uEFI.MemoryChannelMode (docs/X3650M3_UEFI.md section 7 and Appendix A, EXTRACTED). Lockstep is therefore not a selectable mode in that firmware release.

6.1 Independent (normal) mode #

  • "In non-mirroring mode, all three channels on the memory interface for each microprocessor can be populated in any order and have no matching requirements." For performance use the sequence in section 3.2. Source: S-002 Table 10 text; infocenter c_dimm_installation_sequence_option. Level: DOCUMENTED.
  • Minimum configuration: S-002 says the server ships with at least one 2 GB DIMM in slot 3; S-004 / infocenter r_memory_problems say "one 1 GB DIMM in slot 3". See conflict C-2.
  • Each installed CPU needs at least one DIMM. Level: DOCUMENTED (S-002).

6.2 Memory mirroring #

Pair CPUs installed Connectors
1 1 3 + 6
2 1 2 + 5
3 1 1 + 4
4 2 12 + 15
5 2 11 + 14
6 2 10 + 13
  • Pairs are on channel 0 and channel 1 of the same CPU, same connector position (3-6, 2-5, 1-4). Channel 2 connectors 7, 8, 9, 16, 17, 18 are unused in mirroring mode.
  • The two DIMMs of a pair must be identical in size, type, rank (single/dual/quad) and organization; speed may differ (the channels run at the slowest).
  • Addressable memory = half of installed (example: 64 GB installed => 32 GB).
  • Enable: Setup utility -> System Settings -> Memory -> Memory Channel Mode -> Mirroring.
  • Memory for CPU2 may be added as soon as CPU2 is installed.
  • S-001 "Memory options": with mirroring, DIMMs are installed in pairs with a minimum of one pair per CPU.
  • Maximum mirrored capacity with 1 CPU: 6 DIMMs; with 16 GB dual-rank RDIMMs 96 GB installed, 48 GB usable; with two CPUs 192 GB installed, 96 GB usable (derived arithmetic from the rules above). Level: DOCUMENTED rules, derived numbers.

Source: S-002 "Memory mirroring" (Tables 11, 12), infocenter c_memory_mirroring_option. Level: DOCUMENTED. The explanatory prose next to Figures 122 and 123 in the same section contradicts Tables 11/12; the figure labels themselves (text layer) agree with the tables (conflict C-4).

6.3 Online-spare (sparing) #

CPU Connector sets (cumulative)
CPU1 3, 6, 9 -> then add 2, 5, 8 -> then add 1, 4, 7
CPU2 12, 15, 18 -> then 11, 14, 17 -> then 10, 13, 16
  • Supported only on models with a Xeon 5600 series CPU (S-002; S-001 repeats "only supported for Intel Xeon 5600 series").
  • DIMMs are installed three per CPU at a time (one per channel): first DIMM channel 0, second channel 1, spare DIMM channel 2. DIMMs in a set must be identical in size, type, rank, organization; speed may differ.
  • Usable memory = 2/3 of installed (example: 72 GB installed => 48 GB usable).
  • Sparing and mirroring are alternatives: "You can enable either online-spare memory or memory mirroring".
  • Triggering threshold for sparing: Setup question "Spare Error Threshold" (Memory form, docs/X3650M3_UEFI.md section 5, EXTRACTED) / ASU name uEFI.SpareErrorThreshold (S-026); sub-setting of MemoryChannelMode, numeric 0..15, default 15, protected (docs/X3650M3_UEFI.md Appendix A.2, EXTRACTED).

Source: S-002 "Online-spare memory" (Table 13); infocenter c_online_spare_memory_option; S-001 "Memory options". Level: DOCUMENTED.

6.4 Applicability to the owner's machine #

Today only connector 3 is populated, one CPU: independent mode, one channel used (channel 0). Mirroring needs 2 identical DIMMs (3+6); sparing needs 3 identical DIMMs (3+6+9). Level: DOCUMENTED rules (6.2/6.3) applied to the MEASURED installed state (section 9); the conclusion is derived, not a separate truth level.

Notes:

  • Chipkill requires x4-based DIMMs per S-001. The installed DIMM reports SDRAM Device Width: 4 bits (SPD via IPMI FRU), so it is an x4 device module (MEASURED). EDAC reports dimm_dev_type: x8 - conflict C-6 (resolved in favour of SPD x4: the driver derives x8 from the DDR3 bank count, see C-6). Chipkill (x4 SDDC) is active on this machine (CANDIDATE, strong): the Intel Xeon 5600 datasheet vol 2 (Table 3-1, p.57-58) states RDIMMs get x4 SDDC in Independent Channel Mode and x8 SDDC in lockstep, and the Xeon 5500 datasheet vol 2 (321322, sec 2.8.3) defines MC_CONTROL bit 1 ECCEN: "ECCEN without Lockstep enables the x4 SDDC" (DOCUMENTED). Live registers (lspci -s ff:03.0 -xxx, 2026-10-21, MEASURED): MC_CONTROL (0x48) = 0x00000102 (ECCEN = 1, CHANNEL0_ACTIVE = 1, open page), MC_STATUS (0x4C) = 0x1E (ECC_ENABLED, channels 1 and 2 disabled); channel mode Independent (ASU).
  • Mirroring: the datasheet describes mirroring (Ch0 with Ch1, Ch2 empty) for the whole 5500/5600 series without per-SKU exceptions, and TIPS0805 lists mirroring and sparing for the x3650 M3 (DOCUMENTED); availability on the E5606 specifically is CANDIDATE (yes). The live UEFI offers Mirroring and Sparing as choices (uEFI.MemoryChannelMode, ASU showvalues 2026-10-21, MEASURED).
  • EDAC dimm_edac_mode: S8ECD8ED is the i7core_edac driver's label: it maps MC_CONTROL bit 1 to "x8 SDDC" (#define ECCx8(pvt) (mc_control & (1 << 1)), drivers/edac/i7core_edac.c). The Intel datasheet names that bit ECCEN and ties x4 SDDC to it in independent mode, so the label is a driver naming artifact (same pattern as C-6; conflict recorded in 13, resolved in favour of the datasheet).
  • EDAC sdram_scrub_rate: 0 (MEASURED) is the value the OS driver exposes. The firmware patrol scrub is indeed off: live uEFI.PatrolScrub = Disable (ASU show all 2026-10-20 and Setup byte 0x05A1, MEASURED; default Disable).

  • 18 slots require both CPUs: max 288 GB (18x 16 GB dual-rank) at 800 MHz in the all-slots configuration (3 DPC), or 12 slots 16 GB quad-rank for 192 GB, also at 800 MHz (2 quad-rank per channel, S-001). Source: S-001/S-002 limits (section 4.2) and S-001 speed rules. DOCUMENTED.
